# Scroll-Driven Hero Section Animation

Live: https://rohanmishra29.github.io/hero-scroll-next/

Stack: Next.js, React, Tailwind CSS, GSAP (ScrollTrigger)

Features:
- Staggered headline reveal and count-up stats on load
- Scroll-linked car, road and text animation using GSAP ScrollTrigger (pinned and scrubbed)
- Transform-only animation for smooth performance
- Respects prefers-reduced-motion
- Static export deployed to GitHub Pages with GitHub Actions

Vanilla HTML/CSS/JS version: https://github.com/rohanmishra29/hero-scroll-animation
